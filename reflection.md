Reflection on Cloud Services

1. Cloud services I currently use:
I use Google Drive, Gmail, Facebook Messenger, and GitHub. (Change this to the services you really use, for example OneDrive, Dropbox, Canva, or Google Docs.)

2. Service model:

Service	Model	Reason
Google Drive	SaaS	Ready-to-use storage, managed by the provider
Gmail	SaaS	Email used through the browser or app
Google Docs / Microsoft 365	SaaS	Software used online without installing
GitHub	SaaS	Hosted platform for code and version control

These are all SaaS because I just use the software. I don't manage the servers, storage, or operating system.

3. Deployment model:
All of them use the Public Cloud. They are owned by providers like Google, Microsoft, and GitHub, and anyone can sign up and use them over the Internet.

4. Why Git and GitHub are important in cloud computing projects:

Version control: Git records every change, so I can go back to an earlier version if something breaks.
Collaboration: Many people can work on one project and combine their work without overwriting each other.
Backup and access: My code is stored in the cloud, so I can access it from any device and it is safe if my computer fails.
Automation and deployment: Cloud projects often use GitHub to automatically test and deploy code (CI/CD).
Documentation and portfolio: README files and repositories show what I did and what I learned.
